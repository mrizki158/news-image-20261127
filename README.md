## How it is built

`build_image.py` draws the whole picture with PIL shapes only — flat editorial
illustration, no photographs, no AI-generated images. `entry.png` (1024×1024)
is the committed render; `main.py` copies it to `$MAKEFUN_OUTPUT_DIR`
(default `/output`). Both runs write byte-identical output.
